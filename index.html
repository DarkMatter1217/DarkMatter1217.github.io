Research

A Claim-Centric Multi-Source Verification Architecture for Reducing Hallucinations in Retrieval-Augmented Generation

Singh, P. · Amity Journal of Computational Sciences, Vol. 10, Issue 1, 2026

RAG systems usually trust whatever they retrieve. My system, ARA, breaks an answer into separate claims and checks each one against independent evidence from the web. If it can't find support for a claim, it says so instead of guessing.

~80%fewer false "supported" labels than a standard RAG setup
496hand-labeled claims from scientific papers
289 → 56unsupported claims wrongly marked as supported
